A compact 4 KB Python chess engine that plays the house gauntlet through the make.fun env: alpha-beta search on a fixed node budget, deterministic, no clock, no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 -P -s main.py
```
